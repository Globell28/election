"# election"
This application is an decentralized voting system that uses blockchain technology to encourage free and fair elections while protecting the anonymity of users. 
This application explores how Blockchain operates in real-life scenarios and how it can be used as a tool to safeguard electronic voting systems. 
To run on the machine: Clone the file into your local directory, install react and type npm run start to run on localhost. Install Ganache if you want to test the systems. 
Make sure you also have a HD-wallet, preferably, MetaMask as every transaction taken on the blockchain requires a little fee 😊
